# ☕ مشروع كافيه «رُكـن» — كود المتقدم: F-02

> تطبيق طلب مسبق متكامل للقهوة المختصة (Pre-order System) — مبني بـ Flutter مع واجهة عربية RTL كاملة، ودعم الوضعين النهاري والليلي، والربط التجريبي مع Supabase.

---

## 📋 نظرة عامة
تم تصميم وبرمجة هذا النظام وفق متطلبات تحدي «فاريوس» لكافيه قهوة مختصة ناشئ (**ركن**) يستهدف فئة الشباب (18-30 سنة) بنبرة دافئة وبسيطة:
1. **شاشة إنشاء الطلب (Create Order):** استعراض المنيو، تمييز منتج «قهوة اليوم» (بكمية محدودة وتحميص متجدد)، تخصيص الكوب (الحجم، الحليب، السكر، الإضافات)، إدخال اسم العميل بشكل إلزامي وانسيابي، مع شريط عائم ثابت لتأكيد الطلب وحساب الفاتورة بدقة.
2. **شاشة تتبع الطلب (Order Tracking):** خط زمني مباشر لمراحل الطلب الثلاث (جديد / قيد التحضير / جاهز)، مع رمز QR لاستلام الكوب، تفاصيل الباريستا، وملخص مفصل لجميع الأصناف، وحالة احتفالية عند الاكتمال.
3. **شاشة الموظف / الباريستا (Staff Screen):** لوحة تحكم فورية لاستعراض الطلبات الجديدة، وتغيير حالاتها بضغطة زر (تحضير / تسليم / إلغاء)، مع إحصائيات المبيعات النشطة.

---

## 📱 الشاشات الرئيسية الثلاث

| 1) إنشاء طلب | 2) تتبع الطلب | 3) شاشة الموظف |
|:---:|:---:|:---:|
| منيو متجاوب + قهوة اليوم + شريط ثابت | خط زمني مباشر + QR + تفاصيل الفاتورة | تغيير الحالة + إحصائيات فورية |

---

## ✨ أهم المميزات المنفذة

- ☕ **إبراز منتج «قهوة اليوم»** — بطاقة مميزة ببيانات التحميص اليومي المحدود.
- 🏷️ **شريط طلب ثابت (Sticky Action Bar)** — وصول مباشر لإنهاء الطلب وحساب الفاتورة بدون حاجة للتمرير.
- ✍️ **التحقق التفاعلي من اسم العميل** — نافذة سفلية ذكية تطلب الاسم بلباقة وتمنع الطلبات المجهولة.
- 🧾 **فاتورة واقعية ودقيقة 100%** — احتساب دقيق للمشروبات والإضافات بدون خصومات وهمية.
- 📦 **تتبع شامل لكل الأصناف** — عرض تفاصيل كافة عناصر الطلب في التتبع مع مؤشر تقدم الخطوات.
- 🌙 **وضع نهاري وليلي متناسق** — لوحة ألوان دافئة مستوحاة من درجات القهوة والبُن.
- 🔄 **بيانات تجريبية ومزامنة Supabase** — يعمل التطبيق فوراً ببيانات Mock Data مع إمكانية التبديل إلى Supabase.
